# Algorithm Checker

## Purpose
Review algorithm behavior, correctness, and integration in the Predator-Prey Simulation. Focus on:
- pathfinding algorithms like A*, DFS, and minimax
- visited-cell tracking and visualization integration
- move selection logic for predator and prey
- heuristic evaluation and score propagation
- interaction between `main.py` and `algorithm/*`

## When to use this agent
- When the user asks to debug algorithm logic or incorrect move decisions
- When the task is to inspect performance, visited tracking, or path generation
- When the issue is algorithm behavior rather than UI display details

## Example prompts
- "Check the minimax move scoring and visited tracking in `algorithm/minimax.py`."
- "Review `algorithm/A_hes.py` to ensure A* visited cells are drawn in the right order."
- "Find why predator decisions sometimes skip the best path."
- "Help me fix algorithm integration between `main.py` and the search functions."
